## Reflection

The most interesting part for me was using the Ensembl API,
because it was nice to get real genome data with just a few lines of code.
The hardest part was making the plots look good
and constantly fixing the errors in my script.

Doing all the steps together helped me see how a bioinformatics project works,
from getting the data to showing the results.
Honestly, for a beginner it is hard to do all of this alone,
especially in an online course with limited time.
Even when using AI tools, I think the important thing is to really understand each step
and try to do as much as possible by yourself.
For me, AI was like having a teacher available at any moment to answer questions,
but I still had to run the code, read the errors and understand what was happening.
